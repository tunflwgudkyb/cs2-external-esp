# Security Policy

This repository is an **educational external cheat** for Counter-Strike 2.
It is published to help people learn about process memory reading, offset
resolution, and overlay rendering on Windows.

## Supported scope

- Offline / bot matches and local dedicated servers only.
- Do **not** run this against VAC-secured matchmaking. Doing so violates the
  Steam Subscriber Agreement and will get your account banned.

## Reporting a vulnerability

If you find a bug that can crash `cs2.exe`, corrupt memory, or leak the
user's Steam credentials, open a private security advisory on GitHub.
We aim to respond within 72 hours.

## Out of scope

- "Make it undetected" requests.
- Requests for kernel-mode components, DRM bypasses, or spoofer features.
- Anything that facilitates cheating in competitive play.

Use at your own risk. The maintainers accept no liability for account
bans, hardware bans, or ToS violations.
