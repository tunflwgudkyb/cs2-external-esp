Feature set

Everything the overlay renders

Six core modules implemented as an external overlay — each one designed to be read, modified and studied.

📦

Player Box ESP

Draws 2D bounding boxes around visible enemies using projected world-to-screen coordinates, with configurable corner-style outlines.

🦴

Skeleton Rendering

Bone-to-bone line drawing across the head, spine, arms and legs, giving a clean articulated view of every player model.

❤️

Health Bars

Vertical and horizontal health indicators that scale with the projected box height, plus a numeric HP readout and armor tint.

🧭

Radar Hack

A rotating minimap that plots enemy positions relative to your local yaw, with distance labels and team coloring.

🎯

Aimbot Logic

Configurable FOV cone, smoothing curve and bone-target selection — implemented for study of angle calculation math.

✨

Glow & No-Flash

Outline glow pass for player models and a no-flash routine that neutralizes flashbang screen effects for cleaner frame analysis.
